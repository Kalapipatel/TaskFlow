# TaskFlow

TaskFlow is a Jira-inspired task management platform built using a microservices architecture.

## Tech Stack

### Backend
- Java
- Spring Boot
- Spring Cloud
- Spring Security
- MySQL
- Maven

### Frontend
- React
- Tailwind CSS (Planned)

## Project Structure

```
TaskFlow
│
├── backend
│   └── auth-service
│
├── frontend
├── docs
└── README.md
```
